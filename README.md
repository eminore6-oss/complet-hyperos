# HYPEROS A5 PRO FINAL
Launcher Android inspirado visualmente en Xiaomi HyperOS para Redmi A5.

## Incluye
- Inicio con reloj grande, fecha, widget visual y dock.
- Cajón de aplicaciones con búsqueda.
- Temas de acento y modo oscuro.
- Ajustes propios.
- GitHub Actions para compilar un APK debug.

## Compilar
1. Sube el contenido del ZIP a un repositorio GitHub, incluido `.github`.
2. Abre Actions y ejecuta `Build HYPEROS A5 PRO APK`.
3. Descarga el artefacto `HYPEROS-A5-PRO-final-apk`.
4. Extrae `app-debug.apk` e instálalo en el Redmi A5.

## Activar
Ajustes > Aplicaciones > Aplicaciones predeterminadas > App de inicio > HYPEROS A5 PRO.

## Importante
Es un launcher, no la ROM HyperOS. No sustituye la pantalla de bloqueo ni el panel real del sistema. El aspecto final debe comprobarse en el teléfono; este código no se ha probado en un Redmi A5 físico.
